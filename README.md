# Country-Explorer App
Name Hellina Tesfaye ----- ATE/1540/15



# Description 
This is a simple Flutter app that lets users browse information about countries.

The app shows a list of all countries with their flags and region, and when you tap on one, you get more details like the capital city, population, what currencies they use, what languages they speak, and their timezones. 

I used the RestCountries API to get all the data. The app handles loading states (shows a spinner while loading), error states (shows error message if something fails), and has a retry button if there's no internet connection.



# Setup 
- Flutter SDK (latest version)
- Dart SDK
- Android Studio / VS Code
- Android Emulator or physical device 


# Limitations
  - Flag images may load slowly on slow internet connections
  -  App requires internet connection for initial data load
  -  The RestCountries API requires exact or near-exact name matches for search
